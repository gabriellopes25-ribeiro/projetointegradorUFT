# Arquivos __init__.py

Os arquivos src/__init__.py e os __init__.py de models, services, repositories e utils identificam pacotes Python. Atualmente contêm apenas uma descrição, sem regras de negócio nem inicialização de serviços.

A divisão é por responsabilidade; não é uma divisão de funcionalidades isoladas. Uma funcionalidade pode importar classes de vários pacotes. Consulte o [índice](README.md).
